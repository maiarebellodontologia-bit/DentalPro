# DentalPro

Sistema de gestão para clínica odontológica.

## Estrutura

- `frontend/`: aplicação web em React + Vite + TypeScript + Tailwind CSS
- `backend/`: API em Node.js + Express + Prisma + SQLite

## Próximos passos

1. Instalar as dependências em cada projeto.
2. Configurar o banco SQLite com Prisma.
3. Implementar módulos de pacientes, agendamentos e consultas.
